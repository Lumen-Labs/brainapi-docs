## Importing

Start by importing the `Driver` class.

<Tabs items={["Typescript", "Python"]}>
  <Tab value="Typescript">
    <DynamicCodeBlock
      lang="ts"
      code={`import { LumenBrainDriver } from "lumen-brain";

// Initialize the driver with your API key
const brain = new LumenBrainDriver("your-api-key");`}
/>

  </Tab>
  <Tab value="Python">
    <DynamicCodeBlock
      lang="py"
      code={`# Choose between the synchronous and asynchronous drivers

from lumen_brain import LumenBrainDriver
from lumen_brain import AsyncLumenBrainDriver

# Initialize the driver with your API key

brain = LumenBrainDriver("your-api-key")
client = AsyncLumenBrainDriver(api_key="your-api-key")
`}
/>

  </Tab>
</Tabs>

## Retrieving additional context

You can retrieve additional context based on the user's message and append it to the prompt for the LLM.
The additional context will include relevant information extracted from the memory and the conversation history if conversation_id is provided.

<Tabs items={["Typescript", "Python"]}>
  <Tab value="Typescript">
    <DynamicCodeBlock
      lang="ts"
      code={`const queryResult = await brain.queryMemory(
    "What was the test message?",
    "memory-uuid",
    "conversation-123"
);`}
    />
    <TypeTable
      type={{
