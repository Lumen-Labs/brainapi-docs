## Importing

Start by importing the `Driver` class.

<Tabs items={["Typescript", "Python"]}>
  <Tab value="Typescript">
    <DynamicCodeBlock
      lang="ts"
      code={`import { LumenBrainDriver } from "lumen-brain";

// Initialize the driver with your API key
const brain = new LumenBrainDriver("your-api-key");`}
/>

  </Tab>
  <Tab value="Python">
    <DynamicCodeBlock
      lang="py"
      code={`# Choose between the synchronous and asynchronous drivers

from lumen_brain import LumenBrainDriver
from lumen_brain import AsyncLumenBrainDriver

# Initialize the driver with your API key

brain = LumenBrainDriver("your-api-key")
client = AsyncLumenBrainDriver(api_key="your-api-key")
`}
/>

  </Tab>
</Tabs>

## Saving a message

You can save messages from your application during a conversation.
