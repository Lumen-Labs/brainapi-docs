---
title: Context
description: This API provides a way to retrieve the context of an entity in the brain.
---

The context API is available via REST API, Python SDK and Typescript SDK.
It is primarly used to retrieve additional context given some text.

## Usage

It can be called from the Typescript SDK, Python SDK and cURL.

The return type is the following:

<Tabs items={["Typescript", "Python", "cURL"]}>
  <Tab value="Typescript">
    <DynamicCodeBlock
      lang="ts"
      code={`export interface GetContextTriple {
    identified_entity: string;
    triple: [EntityNode, Predicate, EventNode, Predicate, EntityNode];
}

export interface GetContextResponse {
    text_context: string;
    triples: GetContextTriple[];
}`}
    />
  </Tab>
  <Tab value="Python">
    <DynamicCodeBlock
      lang="py"
      code={
        `class GetContextTriple(BaseModel):
        
    identified_entity: str
    triple: Tuple[EntityNode, Predicate, EventNode, Predicate, EntityNode]

class GetContextResponse(BaseModel):

    text_context: str
    triples: List[GetContextTriple]`}

/>

  </Tab>
  <Tab value="cURL">
    <DynamicCodeBlock
      lang="json"
      code={`{
    "text_context": "The CEO of Apple inc. is Tim Cook.",
    "triples": [
        {
            "identified_entity": "Apple inc.",

        }
    ]
}`}

The response will be composed by a unified `text_content` string of all the textual information relevant to the input text,
and a list of **event-centric** relationships rapresenting the information in the brain relevant to the identified noun or entity in the input text.
