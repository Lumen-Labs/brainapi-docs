<Callout type="info">
  In this API **not** all data is used in the analysis, only the data into
  `json_data` and `textual_data` are ingested into the analysis pipeline. The
  metadata is just extra data attached to the node identified/created with the
  `identification_params` parameters + the `types` parameters.
</Callout>

## Usage

The structured data API is available via the REST API, Python SDK, and TypeScript SDK.
The API payload consists of three main sections: `data`, which contains the entities to process; the optional `observate_for` array, which provides tailored instructions to focus the analysis; and `brain_id`, which specifies the target brain identifier.

<Tabs items={["Typescript", "Python", "cURL"]}>
  <Tab value="Typescript">
    The Typescript SDK provides the `ingestStructuredData` function to ingest
    structured data.
    <DynamicCodeBlock
      lang="ts"
      code={`
const result = await brain.ingestStructuredData({
    data: [
        ...processableEntities    
    ],
    observate_for: [], // optional instructions to tailor the analysis
    brain_id: "example01",
});`}
    />
  </Tab>
  <Tab value="Python">
    The Python SDK provides the `ingest_structured_data` method to ingest
    structured data.
    <DynamicCodeBlock
      lang="py"
      code={`result = await client.ingest_structured_data(
    data=processable_entities,
    observate_for=observate_for_instructions,
    brain_id="example01",
)`}
    />
  </Tab>
  <Tab value="cURL">
    Call the POST endpoint with the payload to ingest structured data.
    <DynamicCodeBlock
      lang="bash"
      code={`curl -X POST "<DEPLOYMENT_URL>/ingest/structured" \\
  -H "Content-Type: application/json" \\
  -d '{"data": [...processable_entities], "observate_for": [...observate_for_instructions], "brain_id": "example01"}'`}
    />
  </Tab>
</Tabs>

### `types` parameter in `processableEntity`

Here is where you should attach what type the entity belongs to, since for example we can have a person named `John Doe` and a company named `John Doe`.

### `identification_params` parameter in `processableEntity`

The parameters specified here will be used to attach and connect information within the entity that uniquely identifies with the information provided here.

### `textual_data` parameter in `processableEntity`

This is the section where you should add the more detailed textual information about the entity. Provided as json object where the values are strings.
